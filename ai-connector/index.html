How it works

Plugged in, in three steps

No integrator, no cloud migration. Your software keeps running exactly as it does today.

1

Install the connector

Run one command on the Windows or Linux server next to your database. A guided setup checks the connection and helps you create a read-only database login.

2

Pair it with your account

Enter the pairing code from your dashboard. The connector recognizes your software and what its tables mean.

3

Ask Claude

Add ai-connector to Claude as a custom connector, then ask about clients, quotes, invoices or stock in plain language.

Security

Built so your IT can say yes

Your database never faces the internet, and the AI can look but never touch.

Outbound only

The connector only makes outgoing HTTPS connections. No inbound port, no VPN, and it works through company proxies.

Read-only, enforced on your server

The connector itself refuses any query that could change data, so even our cloud cannot make it write.

Your data is not stored

Results pass through to your assistant. We keep an audit log of which queries ran, never the rows they returned.

One switch to cut access

Stop the connector service and access ends immediately. Run aic service stop or use Windows Services.

FAQ

Questions IT usually asks

Do we need to open a port on our firewall?

No. The connector dials out over HTTPS (port 443), like a browser. Nothing on the internet can connect to your server.

Can the AI change or delete our data?

No. The connector checks every query on your server and refuses anything that writes. We recommend a dedicated read-only database login (setup helps create one), and PostgreSQL queries also run in a read-only transaction.

Do you store our data?

No. Query results go straight to your assistant. We keep an audit log with the query text and time, so you can see what was asked, but never the results.

Which AI assistants are supported?

Every plan includes a built-in AI assistant, so you need no other subscription. If your team uses Claude, connect it too: claude.ai, Claude Desktop and the mobile apps, through custom connectors. ChatGPT, Copilot and Gemini are on the way.

What do we need to install it?

A Windows or Linux machine that can reach your database, and an administrator to run the guided setup. No change to your business software.

How do we stop it?

Stop the connector service, from Windows Services or with aic service stop. Access ends immediately.
